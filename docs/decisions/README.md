# Transitus decision navigation

Canonical Decision Records live in `research/decisions/`. This directory may
contain human-oriented indexes and architectural decision views, but must not
become a second canonical decision store.

## Architectural decision register

- **`accepted`:** decided by the repository owner (transitus#1, 2026-11-26). Acceptance does not authorize implementation or merge.
- **`review`:** recommended by the authoring agent after the adversarial review ([TRN-REV-01](../reviews/adversarial-review.md)); awaiting owner acceptance.
- **`superseded`:** replaced by the record named in its `superseded_by` field.
- **`accepted` + `approval_stage: strategically-approved`:** an owner strategic approval of a DAF Landscape Phase II decision (approved 2026-11-26), recorded under WI-0003. It sits on the first rung of the status ladder (strategically approved → requirements incorporated → evidence gate satisfied → implementation authorized → implemented → validated) and authorizes no expenditure, commitment, deployment or implementation. Praxis permits only draft, review, accepted, superseded or withdrawn in `status`, so the rung is carried in `approval_stage`.
